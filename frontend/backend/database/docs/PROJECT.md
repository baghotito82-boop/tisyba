# TISYBA
Connect • Create • Grow

TISYBA is a global social networking platform.

Platform:
- Web Application
- Progressive Web App (PWA)

Core Features:
- User Registration and Login
- User Profiles
- Follow System
- Posts with Text and Images
- Home Feed
- Likes and Comments
- Search
- Block and Report

Technology:
- React
- Node.js
- PostgreSQL

Our Mission:
To connect people, ideas, communities, skills and opportunities worldwide.
